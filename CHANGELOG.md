# Changelog

## 0.4.0

- One lightweight, agent-neutral skill replaces the divergent installer and guide as the public package.
- Shared instructions, skills, role sources and project knowledge support Claude Code and Codex.
- Structured charter decisions preserve explicit values and leave review policy undecided until chosen.
- Safe, recoverable installation preserves owner content and unrelated hooks; native hook trust is reported separately.
- Stable claims and conditional remote creation prevent duplicate ownership from identical starting commits.
- Named native roles have explicit per-host model bindings and behavioral qualification.
- Cross-lab review uses complete immutable snapshots, strict final responses, actual client model evidence and stale-evidence rejection.
- Optional board/recording/deployment/backup implementations are deferred explicitly; local packaging excludes private evidence and historical inputs.
